# ClaudeToggle

macOS menubar app to toggle Claude Code's CLAUDE.md and skill packs on/off.

![macOS 12+](https://img.shields.io/badge/macOS-12%2B-blue)
![Swift](https://img.shields.io/badge/Swift-5.7%2B-orange)

## Features

- **Menubar icon** — native SF Symbols shield, adapts to light/dark mode
- **Three toggles** — CLAUDE.md master switch, reverse engineering skill pack, pentest skill pack
- **Quick presets** — full / reverse-only / pentest-only / base-only / off
- **Template-based** — CLAUDE.md is assembled from modular template parts
- **Custom app icon** — Core Graphics generated `.icns`

### Menubar States

| Icon | State |
|------|-------|
| `shield.fill` | All enabled |
| `shield.lefthalf.filled` | One pack enabled |
| `shield` | Base config only |
| `shield.slash` | CLAUDE.md disabled |

## Install

```bash
git clone https://github.com/<you>/claude-toggle.git
cd claude-toggle

# Build the .app bundle
bash .claude-toggle/build.sh

# Launch
open ClaudeToggle.app
```

## Setup

1. Edit templates in `.claude-toggle/parts/` to match your CLAUDE.md sections
2. Double-click `ClaudeToggle.app` — a shield icon appears in the menubar
3. Click the icon to toggle skill packs on/off
4. Add to Login Items for auto-start:
   - System Settings → General → Login Items → add `ClaudeToggle.app`

## Project Structure

```
.claude-toggle/
├── build.sh              # Build script (compile + icon generation + .app packaging)
├── config.json           # Toggle state (auto-generated, git-ignored)
├── parts/                # CLAUDE.md template fragments
│   ├── base.md           # Core config (always included when enabled)
│   ├── skill-row-*.md    # Skill pack table rows
│   ├── reverse.md        # Reverse engineering routing section
│   ├── pentest.md        # Pentest routing section
│   ├── priority.md       # Routing priority (only when both packs enabled)
│   └── footer.md         # Tool paths + MCP services
└── src/
    ├── ClaudeToggle.swift # Menubar app source
    ├── GenerateIcon.swift # App icon generator (Core Graphics)
    └── Info.plist         # App bundle config (LSUIElement for menubar-only)
```

## How It Works

Templates in `.claude-toggle/parts/` are the source of truth. When you toggle a switch:

1. `config.json` is updated
2. `CLAUDE.md` is regenerated by concatenating the enabled template parts
3. Disabling CLAUDE.md entirely removes the file — Claude Code loads no project instructions

New Claude Code sessions pick up the change automatically.

## Customization

Edit template files in `.claude-toggle/parts/` to change what goes into your CLAUDE.md. The app assembles them based on which toggles are active.
